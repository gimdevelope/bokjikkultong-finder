# 🍯 복지꿀통 지원금 진단기

6개 질문에 답하면 2026년 정부 지원금을 **조건별 O/X로 판정**하고, **공고 원문 근거와 공식 신청 링크**까지 함께 보여주는 단독 HTML 웹앱입니다.
로그인 없이 바로 진단되고, 결과는 링크로 공유할 수 있습니다.

- 라이브: <https://gimdevelope.github.io/bokjikkultong-finder/> (배포 후)
- 만든 곳: 복지꿀통 · 기준일 2026-11-20

## 무엇이 들어 있나

| 구분 | 내용 |
|---|---|
| 진단 | 6단계 카드 입력 — 출생연도 → 거주 지역 → 가구 형태 → 소득 구간 → 주거 형태 → 관심사 |
| 3단 판정 | `● 요건 충족 가능` / `▲ 추가 확인 필요` / `✕ 조건 미충족` (미충족은 접힌 그룹 + 사유 표시) |
| 원칙 | **정보가 없으면 탈락시키지 않음** — 내 정보에 없는 항목은 ▲로 남기고 무엇이 비었는지 표시 |
| 근거 보기 | 카드마다 `[근거 보기 · 공고 원문]` → 조건별 `공고 기준` vs `내 조건` + **공식 공고 원문 문장 인용** + 출처 링크 |
| 공유 | 카카오톡 공유 바텀시트(나에게 저장·친구에게·링크 복사·카카오 채널), 공고별 해시 링크(`#p-<id>`) |
| 공고 단독 페이지 | `#p-culture` 처럼 해시로 들어오면 그 공고의 기준·원문·신청 링크만 보여주고 "내 조건으로 판정"으로 연결 |
| SEO | Open Graph / Twitter 카드 / canonical / JSON-LD(WebApplication + ItemList) / noscript 공고 목록 |
| 저장 | 대기 등록 이메일만 브라우저 localStorage. 서버 전송 없음 |

## 구조

```
index.html              배포본 (단독 실행, 폰트·캐릭터 base64 인라인, 외부 요청 0)
index.template.html     편집 원본 (__FONT_*, __M_* 토큰)
build.py                템플릿 → index.html (글자 서브셋 폰트 + 캐릭터 인라인)
verify2.js              chrome-headless-shell + CDP 클릭 테스트 · 스크린샷 (390/360/1440)
make_og.py              og-image.png 생성 (1200×630)
og-image.png            공유 미리보기 이미지
shots-v3/               검증 스크린샷
```

```bash
python3 build.py
/workspace/.local/node/bin/node verify2.js                       # 파일 검증
/workspace/.local/node/bin/node verify2.js shots-live https://gimdevelope.github.io/bokjikkultong-finder/   # 라이브 검증
```

## 디자인

- 웜크림·화이트 라이트 톤. 네온·그라데이션 없이 **단색 꿀골드(#FFB800) + 헤어라인 테두리**만 사용.
- 판정 색: 충족 `#0B6B47` / 확인 필요 `#8A5A00` / 미충족 `#9C4433`.
- 모바일 390·360px, 데스크톱 1440px에서 가로 넘침 없음(카드 2열 그리드).

## 주의

- 최종 자격은 접수 기관이 정합니다. 화면 곳곳에 "신청 전 공식 사이트 확인"을 명시했습니다.
- 카카오 SDK 미연결 — '나에게 저장/친구에게'는 **요약 복사 → 카카오톡 붙여넣기** 방식입니다.
- 대기 등록은 서버 저장이 아니라 브라우저 localStorage입니다(프로토타입).
